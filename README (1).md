# Documentation guide

This initial package extracts supporting material referenced in the excluded Appendix Q staging file. The historical LaTeX file is retained as a source record and is not an active appendix or verified methods guide.

Training configuration is unresolved: Q claims one sigmoid output, while Chapter 3 describes two-unit softmax. The historical training table was commented out and is not supplied as an executable specification. Historical baseline/model pairing assertions must be read alongside the current provenance qualifications.

Supplementary tables and numerical plots are staged exports. Copying or hashing them does not establish their numerical reproduction. Qualitative image galleries are withheld from this package pending selection, map-pair and model provenance review. Their dependency hashes are listed to preserve the migration record.

Essential methods remain in dissertation Chapters 3 and 5. Long listings, supplementary numerical exports and operational audit records can live here. Avoid renaming the complete historical Q file to Appendix A.
